# 一、生成随机性控制（最核心）

## 1. **temperature**

- **作用**：控制生成的 **“随机 / 创造力”** 程度。
- 原理：对 logits 做 logits / T，再 softmax。
  - T 越小 → 概率分布越 “尖锐”，只选最可能的 token。拉大概率分布差距。
  - T 越大 → 分布越平滑，低概率 token 也可能被选中。缩小概率分布差距。
- **取值**：0 ~ 2.0（常用 0 ~ 1.0）
- 影响：
  - **T=0**：完全确定，每次输出一样（贪心）。
  - **T↑**：更随机、更多样、更发散、可能胡说。
- 典型场景：
  - 代码 / 事实问答：**0 ~ 0.3**
  - 对话 / 创作：**0.7 ~ 1.0**

------

## 2. **top_k**

- **作用**：只从**概率最高的 K 个 token** 里采样。
- **原理**：截断概率分布，只保留 top K。
- **取值**：1 ~ 无穷大（常用 1 ~ 100）
- 影响：
  - **top_k=1**：完全确定，每次输出一样。
  - **top_k↑**：可选范围变大，更随机。
- 常用：
  - 固定输出：**1**
  - 自然对话：**20 ~ 50**

------

## 3. **top_p（nucleus sampling）**

- 作用：从**累计概率** ≥ p 的最小集合里采样。比 top_k 更智能。
- **取值**：0 ~ 1.0
- 影响：
  - **top_p=0.1**：非常保守、确定。
  - **top_p=0.9 ~ 1.0**：更开放、更随机。
- 常用：
  - 事实类：**0.3 ~ 0.6**
  - 创作类：**0.8 ~ 0.95**

> 实际使用中 **top_k 和 top_p 一般只开一个**。

------

## 4. **seed / random_seed**

- **作用**：固定随机数发生器种子。
- 影响：
  - 相同 seed + 相同参数 → **输出完全一致**。
  - 不同 seed → 结果可能不同。
- **用途**：复现结果、调试、接口稳定输出。

------

# 二、重复 & 多样性控制

## 5. **repetition_penalty**

- **作用**：惩罚**重复出现的 token**，防止一段话反复说。
- 取值：1.0 ~ 2.0
  - 1.0 = 无惩罚
- 影响：
  - 值越大，越不容易重复，但可能破坏连贯性。
- **推荐**：**1.05 ~ 1.2**

------

## 6. **frequency_penalty（OpenAI 系）**

- 作用：按出现次数成比例惩罚。出现越多，惩罚越重。
- 取值：-2.0 ~ 2.0
  - 正数：减少重复
  - 负数：鼓励重复

------

## 7. **presence_penalty（OpenAI 系）**

- **作用**：只要**出现过**就惩罚，不管次数。
- **影响**：更易引入新主题、新概念。
- **取值**：-2.0 ~ 2.0

------

# 三、长度控制

## 8. **max_tokens / max_new_tokens**

- **作用**：限制**最多生成多少 token**。
- 影响：
  - 太短：回答被截断。
  - 太长：浪费、拖沓、可能跑偏。
- 通用：
  - 短问答：**512**
  - 长文 / 报告：**1024 ~ 4096**

------

## 9. **min_tokens**

- **作用**：保证**至少生成多少 token**。
- 很少用。

------

## 10. **stop / stop_sequences**

- **作用**：遇到这些串**立刻停止生成**。
- 例如：`\n`, `###`, `Question:`, `答案：`
- 对**格式控制、结构化输出**极其重要。

------

# 四、解码策略（决定是否随机）

## 11. **do_sample / sampling**

- 布尔开关
  - `True`：使用随机采样（temperature/top_k/top_p 生效）
  - `False`：禁用采样，使用 **greedy search**
- **do_sample=False → 输出完全固定**

------

## 12. **num_beams**

- **作用**：束搜索（Beam Search），保留 N 条最优路径。
- **num_beams=1 → greedy**
- **num_beams>1**：更通顺、稳定，但**缺乏多样性**。
- 常用于：翻译、摘要、代码。

------

# 五、高级控制（较少用，但很关键）

## 13. **length_penalty（beam search 用）**

- 对长序列 / 短序列做惩罚。
- 控制生成长度偏好。

------

## 14. **logit_bias / bias_tokens**

- 强制提升 / 降低某些 token 的概率。
- 用于：
  - 禁止某些词
  - 强制输出格式（如必须输出 JSON）

------

## 15. **stream**

- 布尔：是否**流式输出**（SSE）。
